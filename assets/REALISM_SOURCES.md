This file documents third-party visual source assets and their licensing. Track each before adding it to the site.

## Hangout cannabis foliage photograph

- **Image**: Cannabis-leaf-hemp.jpg, by Lode Van de Velde.
- **Public-domain dedication**: CC0 1.0.
- **Source**: https://commons.wikimedia.org/wiki/File:Cannabis-leaf-hemp.jpg
- **Site usage**: photo layer in the Hangout experience card, darkened and gradient-masked for the existing text design.
- **Current delivery**: Wikimedia thumbnail URL, temporarily hotlinked pending a locally optimized asset. This is an availability dependency, and should not be called production-final until bundled.
- **Not a strain representation**: no cultivar/strain claims are made.
