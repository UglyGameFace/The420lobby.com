# Asset attribution

The Xbox Series controller shown in the hero is a photograph of the genuine Carbon Black Xbox Series X-era controller, by [uKER](https://commons.wikimedia.org/wiki/File:Xbox_Series_Controller_Carbon_Black.jpg), licensed under [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The photograph is displayed without redrawing or alterations to the controller's physical features; CSS provides only presentation effects. The image is currently linked from Wikimedia Commons. Verify external delivery on deployed browsers.

`dank-shield-original.svg` is an original, locally authored website graphic. It is not based on the owner's previously uploaded logo.


Barlow Condensed ExtraBold by Jeremy Tribby, obtained from google/fonts (ofl/barlowcondensed), is bundled for reliable arcade headings under the SIL Open Font License 1.1. See BarlowCondensed-OFL.txt.

The 420 Lobby neon lounge banner and matching header wordmark are original generated artwork supplied for the website. Both shipped WebP files derive from the **same** rendered image (the wordmark is a tighter crop). The original pixels are not redrawn with SVG or CSS; CSS handles only proportional layout and responsive sizing.

The responsive header's live smoke is a **48-frame, transparency-preserving animated WebP** created from the photo-real smoke numerals in the original generated neon lounge artwork. Real wisps are advected between frames, rather than redrawn as SVG glyphs. The companion still WebP is used for reduced-motion / data-saver settings and when the site's FX toggle is off. The full lounge banner remains unchanged in its lower homepage location.
